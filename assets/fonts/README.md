# Roboto for report image watermarks

Unmodified variable font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/roboto

`Roboto[wdth,wght].ttf` is stored as `Roboto.ttf`. The accompanying `OFL.txt`
contains the SIL Open Font License and copyright notice.
The server uses this local font to render report photo watermarks with Sharp.
